# Catch The Insect

A fun and interactive game where you try to catch various insects on the screen before they disappear. The game gets progressively harder as more insects appear.

## Features

- **Insect Selection**: Choose your favorite insect to catch (Fly, Mosquito, Spider, Roach).
- **Timer**: Tracks how long you've been playing.
- **Score Counter**: Increases with each insect you catch.
- **Difficulty Increase**: The game adds more insects as your score increases.
- **Message Display**: A message appears when you reach a score of 20.

## Getting Started

### Prerequisites

You only need a web browser to play this game.

### Installation

1. **Clone the repository**:

    ```bash
    git clone https://github.com/dhrumilcpatel/catch-the-insect.git
    ```

2. **Navigate to the project directory**:

    ```bash
    cd catch-the-insect
    ```

3. **Open `index.html` in your web browser** to start playing the game.

### Usage

1. Start the game by clicking the "Play Game" button.
2. Select your favorite insect from the list.
3. Try to catch the insect by clicking on it as it appears on the screen.
4. The game will get harder as your score increases. Keep an eye on the timer and your score!
